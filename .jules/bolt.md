## 2024-06-25 - React Component Re-renders Due to Zustand Reference Changes
**Learning:** Returning array literals like `[]` inside state selection methods creates a new array reference per evaluation. This causes strictly-typed state stores (like Zustand, which uses `===` checking) to flag the state as updated and force components to re-render, despite the state remaining logically identical (empty).
**Action:** Always provide stable references for empty array or object fallbacks. Use a frozen global constant (`export const EMPTY_ARRAY = Object.freeze([])`) in selector fallbacks moving forward.
