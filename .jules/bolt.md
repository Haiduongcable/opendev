## 2024-06-25 - Prevent Unnecessary Re-renders from Zustand Selectors Returning Array Literals
**Learning:** Using inline array literals `[]` as fallback return values in Zustand selectors (e.g., `state => state.items ?? []`) breaks strict referential equality. Since a new array instance is created on every state evaluation, it forces unnecessary re-renders of the subscribed components, even when the underlying data is actually unchanged (i.e. remains effectively empty/undefined).
**Action:** Always use a shared, stable frozen empty array constant like `export const EMPTY_ARRAY: never[] = Object.freeze([]) as never[];` when returning fallback arrays in Zustand selectors.
