## 2024-06-12 - Prevent Re-renders on State Store Update
**Learning:** Returning a full store state using `useChatStore(state => state)` or `useFileChangesStore()` causes unnecessary re-renders in components when other, unrelated properties within the same store update. In active applications like chat, where properties are changing very frequently, this is a major performance hazard.
**Action:** Always use atomic selectors like `useChatStore(state => state.currentSessionId)` or `useShallow` when returning multiple values to ensure that changes to unrelated states in the store do not trigger a component re-render.
